# FixLens Frontend Client

Modern, responsive web client for **FixLens: Multimodal Visual Hardware & Appliance Diagnostic Intelligence**.

## 🛠️ Tech Stack
- **Framework:** React 19 + Vite 6
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Audio & Accessibility:** Native Web Speech API (`window.speechSynthesis`, `webkitSpeechRecognition`)
- **PDF Generation:** Client-side vector report synthesis

## 🚀 Development Setup
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
```

Built for the **Meta Global AI Developer Hackathon 2026**.
